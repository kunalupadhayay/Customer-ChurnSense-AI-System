# Customer ChurnSense AI System Using ML

A Machine Learning based web application that predicts whether a customer is likely to churn using customer account and usage information.

The Machine Learning model is trained using **Google Colab** and deployed as a web application using **Flask**.

## 🚀 Features

- Customer churn prediction
- Machine Learning based classification
- Logistic Regression model
- Flask web application
- Modern responsive UI
- Customer account and usage inputs
- Input validation
- Real-time prediction
- Churn risk result display

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- HTML
- CSS
- JavaScript
- Google Colab

## 🧠 Machine Learning

The Machine Learning model was developed and trained using **Google Colab**.

The project uses **Logistic Regression** to classify customers into two categories:

- **Low Churn Risk** – Customer is unlikely to churn
- **High Churn Risk** – Customer is likely to churn

The model uses customer account information, calling activity, international usage, voicemail information, and customer service interactions for prediction.
